# Scout V2 开发计划

> 状态：v1 草案 · 2026-06-10 · 前序：[agent-build-plan.md](./agent-build-plan.md)（v1，已完成 12/14）
> 主线（用户已定）：**获客优先** —— 分享报告页是核心抓手；心跳（晨报+草稿入队）作为留存层随后；计费最后。

---

## 0. V2 的使命

V1 回答了"为什么试一下"（30 秒读懂你），V2 回答两个问题：
- **获客**：用户怎么变成分发节点？→ 可分享的 Playbook 报告页
- **留存**：用户第二天为什么回来？→ Scout 每天替你上班（晨报+草稿）

## 1. 范围与顺序

```
阶段 0  v1 收尾（前置，~3-4 天）
        T14 案例引擎 · Claude 质量验收（10 URL 五维评分）· 内测 gate
阶段 1  获客：分享报告页（~3 天）+ 内测启动 + build in public 联动
阶段 2  留存：每日心跳（晨报+草稿入队，~4-5 天）
阶段 3  管理面：日历视图 + Activity 流（~3 天）
阶段 4  学习：ROI 闭环（~3-4 天，有数据依赖，见 §5 风险）
阶段 5  商业化：计费（心跳跑顺后，~1 周）
随后    公开 launch（产品故事完整时）
```

## 2. 任务拆解

### 阶段 0：v1 收尾

**V2-T0a 案例引擎（=v1 T14）**
- `lib/scout/case-match.ts`：从 content/growth-stories 按品类/受众/渠道匹配 1-2 案例
- 注入 social-strategy / first-week-calendar 的 `caseNotes` 钩子；文档含 "Playbook precedent / Modeled on" 段 + growth-story 链接
- AC：10 测试 URL ≥8 个匹配合理（人工判定不牵强）；不匹配优雅省略

**V2-T0b Claude 质量验收**
- 前置：OpenRouter 充值（~$20）
- SCOUT_MODEL 切 `anthropic/claude-sonnet-4.6` 跑 10 测试 URL，按 spec §5 五维评分（重点：杜绝推算数字，如 v1 发现的 "$1,860/year"）
- 产出：每份文档生成器的 prompt 迭代；最终模型策略定档（全 Claude vs 合成 Claude + 文档 DeepSeek 的混合，按质量差距定）
- AC：10/10 平均 ≥4 无单项 ≤2

**V2-T0c 内测 gate**
- 邀请码（环境变量白名单或 invite_codes 表，xgrower_invite_codes 模式现成可抄）
- /scout hero 对无邀请用户显示候补表单（留邮箱）
- AC：3 个外部用户走通全链路

### 阶段 1：分享报告页（获客核心）

**V2-T1 公开报告路由 + 精排版页**
- 新表 `scout_reports`：`id, workspace_id, slug(公开短链), enabled, view_count, created_at`
- `/scout/report/[slug]`：无需登录的只读页——7 份文档精排版（阅读视图复用）+ 品牌色头部 + "Generated by Scout in ~3 minutes" + 底部 CTA "Get yours free"
- OG 卡片（标题 + 品牌名 + Scout 徽标）让链接在 X/微信里有预览
- AC：未登录访客完整可读；CTA → /scout hero；view_count 计数

**V2-T2 分享开关与入口**
- 工作台右栏 + onboarding 完成消息里加 "Share your playbook" 按钮 → 生成/复制链接
- 隐私默认（待决策 D1）
- Scout 在 onboarding done 的总结里主动提一句分享（话术自然，不硬推）
- AC：开关可逆（关闭后 404）；分享事件打点（谁分享了、链接被看几次）

### 阶段 2：每日心跳

**V2-T3 心跳 pipeline**
- `lib/scout/heartbeat.ts`：读知识库摘要 + memory + 队列空缺 → radar/trend 扫领域 → 起草 2-3 条帖子（平台按 social-strategy 优先级轮转）→ insertScheduledPost(proposed)
- 晨报消息：Scout 主动往 Direct Chat 发一条（"今天值得蹭的点是 X，我拟了 3 条草稿在队列里"）——新增 system-initiated message 路径（appendMessage role=assistant + 工作台未读标记）
- vercel.json 加 cron（节奏待决策 D2）；幂等（当日已跑则跳过）；预算计入 $3/天闸内
- AC：连续 3 天产出不重复、贴知识库的草稿；队列已满（>5 条 proposed 未处理）时自动降频并在晨报说明

**V2-T4 晨报触达（待决策 D3）**
- 站内：左栏 Direct Chat 未读红点 + 晨报置顶
- 邮件（若 D3 选做）：每日摘要邮件（趋势 + 草稿预览 + 一键进工作台）

### 阶段 3：管理面

**V2-T5 日历视图**
- `/scout/[id]/calendar`：周/月视图渲染 gtm_scheduled_posts，状态色（proposed 橙/scheduled 实心/posted 灰/failed 红）
- 拖拽改期（仅 proposed/scheduled）；点击打开右栏同款编辑面板
- AC：改期落库；与队列面板数据一致

**V2-T6 Activity 流**
- `/scout/[id]/activity`：已发/失败帖子时间流 + 外链到平台原帖（external_post_id）
- AC：发布成功的帖子 5 分钟内出现在流里

### 阶段 4：ROI 学习闭环

**V2-T7 指标回拉（有外部约束，见 §5）**
- Reddit：公开 JSON 可抓（score/comments），零成本先做
- X：API 免费档不可读指标（Basic $200/月）——v2 先用「点击数代理」（短链/UTM 进自家 analytics）替代，X 官方指标推迟到付费验证后
- LinkedIn：organic 指标 API 受限，同 X 处理
- AC：Reddit 帖发布 24h 后 score/评论数入库

**V2-T8 学习注入**
- 发布满 N 条后触发 post-roi 分析 → 结论写 memory（"pain hook 在 Reddit 表现最好"）→ workspaceContext 注入 → 心跳/draft_posts 引用
- 晨报里展示学习（"上周你的 question 帖互动是平均的 2.3 倍，今天的草稿沿用了这个结构"）
- AC：能在生成的草稿里观察到学习痕迹（人工判定）

### 阶段 5：计费

**V2-T9 计费**（基线=决策 4.8：对话免费限量、发布自动化付费）
- 免费：onboarding + 知识库 + 对话限量 + 1 workspace + 手动 approve 发布限量（如 5 帖/月）
- Pro（定价待决策 D4）：心跳 + 无限发布 + 3 workspaces + 优先模型
- Stripe checkout + webhook（仓库已有 orders/webhook_events 基建可参考）
- AC：升级/降级/到期全链路；限额触发时 Scout 话术得体

## 3. 已定决策（本轮讨论）

- ✅ V2 主线 = 获客优先（分享报告页为核心抓手）；公开 launch 放心跳之后
- ✅ 心跳形态 = 晨报 + 草稿入队（Scout 主动发消息 + proposed 队列）
- ✅ v1 收尾三件事下次会话先做（阶段 0 前置）

## 4. 决策记录（D1-D5，2026-06-11 全部敲定）

- ✅ **D1 分享默认 = 默认私有，一键开启**。报告含竞品分析属用户商业信息；Scout 在 onboarding 总结里自然提一句分享即可
- ✅ **D2 心跳节奏 = 工作日每天，设置可调**（每天/每周/关闭）。贴真实发帖节奏，成本省 2/7
- ✅ **D3 晨报触达 = 站内先行**（未读红点+置顶），邮件放 v2.5——先验证晨报内容质量再上放大器
- ✅ **D4 定价 = 内测数据后定**，文档占位 $29/mo 不对外
- ✅ **D5 报告页 SEO = 用户开启分享的页面允许收录**（同意分享=同意公开），程序化 SEO 收敛版的伏笔自然埋下；未分享页面不存在公开路由

## 5. 风险与外部约束

- **X/LinkedIn 指标 API 是付费墙**（X Basic $200/月）——ROI 闭环 v2 用 Reddit 公开数据 + UTM 点击代理起步，官方指标等收入证明后再买
- **心跳成本**：每 workspace 每天 ~3-5 次模型调用（DeepSeek ~$0.01，Claude ~$0.1）——免费用户规模化后心跳是最大成本项，计费分层时要把心跳频率作为杠杆
- **分享页内容风险**：用户分享的报告含竞品对比，措辞失当可能引纠纷——生成规则已有"诚实评价"约束，报告页加免责行（"AI-generated analysis"）
- **晨报疲劳**：连续几天草稿没被 approve 应自动降频、改为每周摘要——别让队友变成闹钟
